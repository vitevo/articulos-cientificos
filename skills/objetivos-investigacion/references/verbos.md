# Verbos para objetivos

Lista de apoyo (convención metodológica general, no tomada de Fortanet ni de Belcher). Elige el verbo por la operación que el estudio realmente puede hacer con sus datos.

## Por propósito del estudio

| Propósito | Verbos | Enfoque típico |
|---|---|---|
| Describir / caracterizar | describir, caracterizar, identificar, mapear, tipificar | cuanti, cuali |
| Comparar | comparar, contrastar, diferenciar | cuanti, cuali |
| Relacionar / asociar | determinar la relación, establecer la asociación, correlacionar | cuanti |
| Explicar / probar efecto | determinar el efecto, evaluar el impacto, explicar, estimar | cuanti, experimental |
| Interpretar / comprender | interpretar, comprender (cómo/qué sentido), explorar (en estudios exploratorios), develar, reconstruir | cuali |
| Analizar | analizar (siempre con un "qué aspecto" o "desde qué marco") | todos |
| Proponer / diseñar / validar | diseñar, proponer, desarrollar, validar | investigación aplicada, diseño, ingeniería |
| Evaluar | evaluar, valorar (con criterio declarado) | evaluativa, mixta |

## Verbos a evitar o precisar

| Verbo | Problema | Alternativa |
|---|---|---|
| conocer, saber, ver | no indican operación investigativa | identificar, describir, determinar |
| realizar, hacer, efectuar | nombran una actividad, no un conocimiento | el verbo de lo que se obtiene |
| aplicar (una encuesta, entrevistas) | es procedimiento: va en el método | describir/analizar lo que se obtiene con ese instrumento |
| revisar la literatura, recopilar | tarea, no objetivo | eliminar o convertir en "sistematizar el estado de…" solo si es una revisión |
| entender, comprender (sin objeto acotado) | demasiado amplio | comprender cómo [actores] significan [fenómeno] en [contexto] |
| mejorar, solucionar, fomentar, promover | objetivo de intervención, no de investigación | evaluar el efecto de [intervención] sobre [resultado] |
| demostrar, probar (que X) | presupone el resultado | determinar si / en qué medida |
| estudiar, investigar, abordar | redundantes y vagos | el verbo específico |

## Señales de objetivo mal construido
- Dos verbos coordinados ("analizar y proponer"): suelen ser dos objetivos.
- Infinitivo encadenado a un fin práctico ("…para mejorar la calidad educativa"): el fin va en la justificación.
- Específicos que son pasos ("aplicar", "procesar", "tabular"): pertenecen al método.
- Específico idéntico al general con otras palabras.
