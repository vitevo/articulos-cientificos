## 6. Mapa temático

Por defecto, árbol en texto (funciona en cualquier salida):

```
TEMA 1: Nombre
├── Subtema 1.1: …
└── Subtema 1.2: …
TEMA 2: Nombre
└── Subtema 2.1: …
  (relación: Tema 1 ↔ Tema 2 — tensión entre …)
```

Si el entorno permite diagramas, dibuja el mapa (temas como nodos principales, subtemas conectados, relaciones entre temas rotuladas). Para mostrar la evolución, presenta el mapa inicial, el revisado y el final.
